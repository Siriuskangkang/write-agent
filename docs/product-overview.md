# 产品范围

## 产品目标

灵思睿著帮助教材编写者把分散素材转化为可编辑、可引用、可导出的教材内容。系统强调素材约束、生成过程可恢复和版本可追溯，而不是提供无限制的通用聊天。

## 目标用户

- 教材主编、课程负责人和职业教育教师
- 需要从白皮书、课件、讲义中组织长内容的团队
- 负责体例统一、引用审查和最终导出的编辑人员

## 核心流程

1. 创建教材项目，填写教材类型、对象、章节目标等基础信息。
2. 上传 PDF、DOCX、PPTX、Markdown 或 TXT 素材。
3. Worker 校验并解析文件，生成结构化文档和检索分块。
4. 生成目录、大纲或正文，并在工作台继续编辑。
5. 查看引用和素材缺口，必要时补充资料后恢复任务。
6. 对正文进行改写、扩写或精简。
7. 导出 DOCX 或 Markdown。

## 能力状态

### 稳定路径

- 用户认证、项目和素材管理
- 异步文件解析与结构化切块
- 目录、大纲、正文生成
- 改写、扩写、精简
- 工作流任务、事件和取消状态持久化
- 体例模板和 DOCX/Markdown 导出

### 渐进能力

- Hybrid RAG 已实现，默认 `shadow`，未通过生产评测门禁前不替换 legacy 结果。
- Claim-evidence ledger 已提供数据结构和验证链路，Atomic Grounding 默认关闭。
- 确定性写作工作流默认关闭，只能对明确项目白名单启用。
- 人工审批属于确定性工作流的一部分，不是默认生成链路的强制步骤。
- Storage Broker 当前不是公开部署能力，默认保持 `legacy`。

## 非目标

- 不把未经验证的模型输出自动发布为正式教材。
- 不在仓库中保存用户上传素材或生成导出物。
- 不承诺默认配置下的 Hybrid 检索已经优于 legacy；切换必须以真实语料评测为依据。
- 不用自由自治多 Agent 替代可恢复、可审计的确定性工作流。
