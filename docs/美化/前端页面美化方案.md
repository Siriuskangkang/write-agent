# 前端页面美化方案

> 基准参考：`/projects` 页面（已完成美化，不做改动）
> 设计系统：蓝色冷色调 SaaS 风格，所有色值统一使用 `globals.css` 中定义的 CSS 变量，禁止硬编码色值

---

## 设计系统规范（所有页面统一遵守）

### 色彩变量映射

| 成功绿 | `var(--brand-success)` | #10B981 |

| 警告黄 | `var(--brand-warning)` | #F59E0B |

| 占位文字 | `var(--text-tertiary)` | #AAAAAA |
| 反色文字 | `var(--text-inverse)` | #FFFFFF |

> `globals.css` 已补充以下新变量：`--brand-success`、`--brand-success-light`、`--brand-success-border`、`--brand-danger-light`、`--brand-danger-border`、`--text-primary`、`--text-secondary`、`--text-tertiary`、`--text-inverse`、`--shadow-card`、`--shadow-card-hover`、`--shadow-modal`、`--shadow-login`、`--radius-xl`、`--radius-2xl`

### 圆角变量

| 场景 | 变量 | 值 |
|------|------|----|
| tag、badge、小元素 | `var(--radius-sm)` | 4px |
| 按钮、输入框 | `var(--radius-md)` | 6px |
| 内容区、面板 | `var(--radius-lg)` | 8px |
| 卡片、列表容器 | `var(--radius-xl)` | 10px |
| 大卡片、弹窗、登录框 | `var(--radius-2xl)` | 12px |

### 阴影变量

| 场景 | 变量 |
|------|------|
| 默认卡片 | `var(--shadow-card)` |
| hover 卡片 | `var(--shadow-card-hover)` |
| 弹窗 | `var(--shadow-modal)` |
| 登录卡片 | `var(--shadow-login)` |

### 字体

- 字号体系：11px（辅助）/ 12px（标签）/ 13px（正文）/ 20px（页面标题）
- 字重：400（正文）/ 500（次要强调）/ 600（标题）/ 700（大标题）
- 字体栈：`var(--font-sans)`

### 动效

- 过渡时长：`var(--transition)`（0.15s ease，交互反馈）/ `0.2s`（卡片 hover）
- 卡片入场：`cardEnter` 动画（fade + slide up，stagger 60ms）
- 按钮 hover：`translateY(-1px)` 上浮

## 一、登录页 `/login`

### 现状问题

- 背景使用紫色渐变，与整体蓝色系不符
- 卡片无品牌标识，视觉层次单薄
- 表单输入框样式与全局设计系统脱节

### 美化方案

#### 1. 背景

改为蓝色系渐变，与品牌色统一：

```css
background: linear-gradient(135deg, #1E3A5F 0%, var(--brand-primary) 50%, #0EA5E9 100%)
```

> 注：渐变的起止色 `#1E3A5F`（深海蓝）和 `#0EA5E9`（天蓝）是渐变专用装饰色，不属于语义色，可直接写值或新增 `--brand-gradient-start / end` 变量。

叠加两个半透明装饰光晕：
- 左上角：`width: 400px; height: 400px; background: rgba(255,255,255,0.06); border-radius: 50%; filter: blur(60px)`
- 右下角：`width: 300px; height: 300px; background: rgba(96,165,250,0.15); border-radius: 50%; filter: blur(40px)`

#### 2. 卡片

```
width: 420px
border-radius: var(--radius-2xl)
box-shadow: var(--shadow-login)
background: var(--surface-card)
backdrop-filter: blur(20px)
padding: 40px 36px 36px
```

#### 3. 品牌 Logo 区域

```
// Logo 图标（蓝色渐变方块 + 三条线，与 projects topbar 一致）
width: 40px; height: 40px; border-radius: 10px
background: linear-gradient(135deg, var(--brand-primary), var(--brand-accent))

// 标题
font-size: 22px; font-weight: 700; color: var(--text-primary); letter-spacing: -0.03em

// 副标题
font-size: 13px; color: var(--text-secondary)
```

#### 4. 表单输入框

```
height: 40px
border: 1px solid var(--surface-border)
border-radius: var(--radius-lg)
// focus
border-color: var(--brand-primary)
// prefix 图标
color: var(--text-tertiary)
```

#### 5. 登录按钮

```
height: 40px
background: var(--brand-primary)
border-radius: var(--radius-lg)
font-size: 14px; font-weight: 600; color: var(--text-inverse)
// hover
background: var(--brand-primary-hover); transform: translateY(-1px)
// 添加 btn-shimmer 扫光动效（复用 globals.css 已有类）
```

#### 6. 底部链接

```
font-size: 13px; color: var(--text-secondary)
// 链接
color: var(--brand-primary)
```
