   - 后端开发：查看 02、03 文档
   - 前端开发：查看 04 文档
   - 测试工程师：查看 05 文档

- 代码规范：遵循项目 ESLint/Prettier 配置
- 提交规范：Conventional Commits（feat/fix/refactor/docs/test/chore）
- 测试覆盖率：≥ 80%
- 代码审查：所有 PR 需至少 1 人 Review
