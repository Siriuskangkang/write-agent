## 阶段二：API 接口测试

### 2.1 健康检查

```bash
curl http://localhost:3002/api/health
```

**预期**：返回 200 状态码

### 2.2 创建体例模板

```bash
curl -X POST http://localhost:3002/api/style-templates \
  -H "Content-Type: application/json" \
  -H "Cookie: wa_access_token=YOUR_TOKEN" \
  -d '{
    "name": "测试体例",
    "description": "测试用体例模板",
    "projectId": "PROJECT_ID",
    "referenceFileIds": []
  }'
```

**预期**：
- 返回 201 状态码
- 返回创建的模板对象
- 包含 id、name、status 等字段

### 2.3 获取模板列表

```bash
curl http://localhost:3002/api/style-templates?projectId=PROJECT_ID \
  -H "Cookie: wa_access_token=YOUR_TOKEN"
```

**预期**：
- 返回 200 状态码
- 返回模板数组

### 2.4 获取模板详情

```bash
curl http://localhost:3002/api/style-templates/TEMPLATE_ID \
  -H "Cookie: wa_access_token=YOUR_TOKEN"
```

**预期**：
- 返回 200 状态码
- 返回完整的模板对象

### 2.5 更新模板

```bash
curl -X PATCH http://localhost:3002/api/style-templates/TEMPLATE_ID \
  -H "Content-Type: application/json" \
  -H "Cookie: wa_access_token=YOUR_TOKEN" \
  -d '{
    "name": "更新后的体例名称"
  }'
```

**预期**：
- 返回 200 状态码
- 返回更新后的模板对象

### 2.6 删除模板

```bash
curl -X DELETE http://localhost:3002/api/style-templates/TEMPLATE_ID \
  -H "Cookie: wa_access_token=YOUR_TOKEN"
```

**预期**：
- 返回 200 状态码
