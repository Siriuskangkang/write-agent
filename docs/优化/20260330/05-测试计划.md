# 体例管理功能测试计划

## 1. 测试策略

### 1.1 测试层级

- **单元测试**：覆盖核心业务逻辑，独立测试各服务和工具类

### 1.2 覆盖率要求

- 整体代码覆盖率 ≥ 80%
- 核心业务逻辑覆盖率 ≥ 90%
- 关键路径必须 100% 覆盖

### 1.3 测试工具

- **后端**：Jest + Supertest
- **前端**：Jest + React Testing Library
- **E2E**：Playwright

## 4. E2E 测试

### 4.1 完整流程测试场景

**场景 1：创建并应用体例模板**

1. 用户登录
2. 上传参考文档
3. 创建体例模板
4. 创建新项目
5. 应用体例模板
6. 验证生成内容符合体例

**场景 2：管理体例模板**

1. 用户登录
2. 查看模板列表
3. 编辑模板
4. 删除模板
5. 验证操作成功

### 4.2 Playwright 测试脚本示例

**文件位置**：`e2e/style-template.spec.ts`

```typescript
import { test, expect } from '@playwright/test';

test.describe('体例模板管理', () => {
  test.beforeEach(async ({ page }) => {
    // 登录
    await page.goto('http://localhost:8002/login');
    await page.fill('input[name="email"]', 'test@test.com');
    await page.fill('input[name="password"]', 'Test1234!');
    await page.click('button[type="submit"]');
    await page.waitForURL('**/projects');
  });

  test('创建体例模板', async ({ page }) => {
    // 进入模板管理
    await page.goto('http://localhost:8002/style-templates');

    // 点击创建按钮
    await page.click('button:has-text("创建模板")');

    // 填写表单
    await page.fill('input[name="name"]', 'E2E 测试模板');
    await page.fill('textarea[name="description"]', '自动化测试');

    // 提交
    await page.click('button:has-text("确定")');

    // 验证成功
    await expect(page.locator('text=创建成功')).toBeVisible();
    await expect(page.locator('text=E2E 测试模板')).toBeVisible();
  });

  test('应用体例模板', async ({ page }) => {
    // 进入项目
    await page.click('text=测试项目');

    // 打开体例选择
    await page.click('button:has-text("应用体例")');

    // 选择模板
    await page.click('text=E2E 测试模板');

    // 确认应用
    await page.click('button:has-text("应用")');

    // 验证应用中
    await expect(page.locator('text=应用中')).toBeVisible();

    // 等待完成
    await page.waitForSelector('text=应用成功', { timeout: 30000 });
  });
});
```

## 6. 测试执行

### 6.1 运行所有测试

```bash
# 后端单元测试
cd backend && npm run test

# 后端集成测试
cd backend && npm run test:e2e

# 前端测试
cd frontend && npm run test

# E2E 测试
npx playwright test
```

### 6.2 测试覆盖率报告

```bash
# 生成覆盖率报告
cd backend && npm run test:cov

# 查看报告

```

在 CI/CD 流程中自动运行测试：

