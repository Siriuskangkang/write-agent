**文件：`backend/src/style-template/style-template.service.ts`**

**状态：修改**

**新增方法：**
```typescript
async getProjectActiveTemplate(projectId: string): Promise<StyleTemplate | null> {
  return this.styleTemplateRepository.findOne({
    where: {
      projectId,
      status: 'completed',
    },
    order: {
      updatedAt: 'DESC',
    },
  });
}
```

**说明：**
- 获取项目的已完成体例
- 按更新时间倒序，取最新的
- 如果没有返回 null

**影响：**
- ContentService 会调用此方法

```typescript
private buildStyleContext(features: StyleFeatures): string {
  return `
## 体例规范

请严格遵循以下体例规范：

### 结构规范
- 章节格式：${features.structure?.chapterFormat || '第X章'}
- 小节格式：${features.structure?.sectionFormat || 'X.X'}
- 最大层级：${features.structure?.maxDepth || 3}

### 语言风格
- 语气：${features.language?.tone || 'formal'}
- 人称：${features.language?.person || 'third'}
- 时态：${features.language?.tense || 'present'}
  `.trim();
}
```

**修改 initDirectorySse 方法：**
```typescript
async *initDirectorySse(projectId: string, dto: GenerateDirectoryDto) {
  // 1. 检查体例（新增）
  const template = await this.styleTemplateService.getProjectActiveTemplate(projectId);
  
  if (!template || !template.features) {
    throw new BadRequestException('请先上传并分析体例文件');
  }

  // 2. 构建体例上下文（新增）
  const styleContext = this.buildStyleContext(template.features);

  // 3. 传递给 chain（修改）
  const context: DirectoryChainInput = {
    projectId,
    userInput: dto.userInput,
    styleContext,  // 新增字段
  };

  // 原有逻辑...
}
```

**说明：**
- 生成目录前强制检查体例
- 将体例特征转换为文本注入 prompt

**同样修改：**
- `initOutlineSse` - 大纲生成
- `initContentSse` - 正文生成
