# 正文生成改造方案

## 问题

当前正文 prompt 按普通 Markdown 段落生成，没有按体例栏目分段输出。生成的正文是连续的知识讲解，而体例要求的是"任务情境→任务目标→知识链接→任务实施→任务评价"的结构化栏目。

---

## 改造范围

1. `content.prompt.ts` — 按栏目顺序输出正文
2. 正文解析/存储 — 支持栏目标记
3. 前端正文展示 — 按栏目渲染

---

## 1. content.prompt.ts 改造

### 当前输出格式

```markdown
<!-- paragraph_key:p1 -->
段落正文内容...

<!-- citations:p1 -->
- [chunk_id](use_type: rewrite) 引用说明
```

### 新输出格式（栏目驱动）

```markdown
<!-- column:任务情境 -->
<!-- paragraph_key:p1 -->
在某工厂的生产线上，质检员小李每天需要人工检查数千个零件...

<!-- citations:p1 -->
- [chunk_001](use_type: summarize) 工业AI应用场景

<!-- column:任务目标 -->
<!-- paragraph_key:p2 -->
完成本任务后，你将能够：
1. 说出人工智能在工业质检中的应用原理
2. 使用图像识别工具完成简单的缺陷检测

<!-- column:知识链接 -->
<!-- paragraph_key:p3 -->
**图像识别技术**是人工智能的重要分支...

<!-- citations:p3 -->
- [chunk_002](use_type: rewrite) 图像识别原理

<!-- column:任务实施 -->
<!-- paragraph_key:p4 -->
**步骤1：** 打开图像识别平台，上传待检测图片...

**步骤2：** 设置检测参数，选择"缺陷检测"模式...

<!-- column:任务评价 -->
<!-- paragraph_key:p5 -->
| 评价维度 | 优秀 | 良好 | 合格 |
|---|---|---|---|
| 知识掌握 | 能准确说出原理 | 基本理解 | 了解概念 |
```

### 改造后的 prompt 关键部分

```typescript
export function buildContentPrompt(params: {...}): string {
  return `...
## 写作要求
1. 必须按大纲中的栏目顺序逐栏输出
2. 每个栏目以 <!-- column:栏目名称 --> 标记开头
3. 栏目内每个段落以 <!-- paragraph_key:pX --> 标记开头
4. 严格遵循每个栏目的篇幅建议和写作要点
5. 任务实施栏目必须使用"步骤1、步骤2..."编号
6. 任务评价栏目必须输出表格格式

## 输出格式
<!-- column:栏目名称 -->
<!-- paragraph_key:p1 -->
正文内容...

<!-- citations:p1 -->
- [chunk_id](use_type: rewrite|summarize|synthesize) 引用说明

依次输出所有栏目。
`;
}
```

## 2. 解析逻辑

正文存储在 `writing_results.content_text`，当前直接存 Markdown 字符串。

新增解析函数，将 `<!-- column:xxx -->` 标记解析为结构化数据，用于前端分栏展示：

```typescript
function parseContentByColumns(text: string): ColumnSection[] {
  const sections: ColumnSection[] = [];
  const parts = text.split(/<!-- column:(.*?) -->/);
  // parts[0] 是开头无栏目的内容（忽略）
  // parts[1,3,5...] 是栏目名，parts[2,4,6...] 是对应内容
  for (let i = 1; i < parts.length; i += 2) {
    sections.push({
      column: parts[i].trim(),
      content: parts[i + 1]?.trim() || '',
    });
  }
  return sections;
}
```

存储不变，仍存原始 Markdown，解析在前端展示时进行。

---

## 3. 前端正文展示改造

### 改造后

```tsx
function ContentDisplay({ content }: { content: string }) {
  const sections = parseContentByColumns(content);

  if (sections.length === 0) {
    // 旧格式，直接渲染 Markdown
    return <MarkdownRenderer content={content} />;
  }

  return (
    <Space direction="vertical" style={{ width: '100%' }}>
      {sections.map((sec) => (
        <Card key={sec.column} size="small"
          title={<Tag color="blue">{sec.column}</Tag>}
          style={{ marginBottom: 8 }}
        >
          <MarkdownRenderer content={sec.content} />
        </Card>
      ))}
    </Space>
  );
}
```

---

## 改造顺序

1. 改 `content.prompt.ts`（添加栏目标记要求）
2. 改前端正文展示（解析栏目标记，兼容旧格式）
3. 测试：重新生成正文，验证栏目结构正确

---

## 兼容性说明

- 旧正文（无 `<!-- column:xxx -->` 标记）：直接渲染 Markdown，不受影响
- 新正文：按栏目分卡片展示
- 改写/扩写/精简 prompt 也需同步添加"保留栏目标记"的要求
