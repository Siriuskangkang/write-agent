## 二、AgentService 改动

### 2.1 修改 agent.service.ts
**文件：`backend/src/agent/agent.service.ts`**

**状态：修改**

**删除的代码：**
```typescript
// 删除
import Anthropic from '@anthropic-ai/sdk';

// 删除
private readonly client: Anthropic;
private readonly model: string;

// 删除构造函数中的初始化代码（约20行）
```

**新增的代码：**
```typescript
// 新增导入
import { LLMFactory } from '../llm/llm.factory';
import { LLMProvider } from '../llm/llm.interface';

// 新增属性
private llmProvider: LLMProvider;

// 修改构造函数
constructor(
  private readonly configService: ConfigService,
  private readonly llmFactory: LLMFactory,  // 新增
) {
  this.llmProvider = this.llmFactory.createProvider();
}

// streamCompletion 方法改为
async *streamCompletion(prompt: string, systemPrompt?: string) {
  yield* this.llmProvider.streamCompletion(prompt, systemPrompt);
}
```

**影响范围：**
- generateStream 方法不变
- 所有 chain 调用不变
