## 六、风险评估

### 6.1 高风险项

**LLM 抽象层改造**
- **风险**：涉及核心 AgentService，影响所有生成功能
- **缓解措施**：
  - 充分测试两种模式
  - 保持向后兼容（默认 anthropic）
  - 分阶段部署

### 6.2 中风险项

**体例注入 prompt**
- **风险**：可能增加 token 使用量
- **缓解措施**：
  - 监控 token 消耗
  - 优化体例上下文长度

### 6.3 低风险项

**体例编辑功能**
- **风险**：新增功能，不影响现有流程
- **缓解措施**：充分测试编辑保存流程
