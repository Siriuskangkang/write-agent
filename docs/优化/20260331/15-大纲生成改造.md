# 大纲生成改造方案

## 问题

当前大纲 prompt 输出固定结构（`objectives / key_points / structure`），没有体现体例要求的栏目（任务情境、任务目标、知识链接、任务实施、任务评价等）。

---

## 改造范围

1. `outline.prompt.ts` — 输出结构改为体例栏目列表
2. 大纲解析逻辑 — 适配新结构
3. 前端大纲展示 — 按栏目渲染

---

## 1. outline.prompt.ts 改造

### 当前输出格式

```json
{
  "objectives": ["学习目标1"],
  "key_points": [{ "point": "知识点", "source": "来源" }],
  "structure": [{ "section": "段落1", "summary": "概述" }],
  "case_suggestions": ["案例建议"],
  "highlights": { "key_points": ["重点"], "difficulties": ["难点"] }
}
```

### 新输出格式（体例栏目驱动）

```json
{
  "node_title": "任务1 认识身边的人工智能",
  "level": "任务",
  "sections": [
    {
      "column": "任务情境",
      "required": true,
      "writing_guide": "描述一个需要运用本任务知识技能来解决的具体问题",
      "length_suggestion": "100-200字",
      "content_points": ["具体要写的内容要点1", "内容要点2"]
    },
    {
      "column": "任务目标",
      "required": true,
      "writing_guide": "清晰说明完成本任务后，学生具体能做出什么",
      "length_suggestion": "1-2条",
      "content_points": ["目标1", "目标2"]
    },
    {
      "column": "知识链接",
      "required": true,
```

### 改造后的 prompt 关键部分

```typescript
export function buildOutlinePrompt(params: {...}): string {
  // 从 stylePrompt 中提取当前节点层级对应的栏目列表
  // stylePrompt 已包含完整的栏目规范，直接告知 AI 按栏目生成

  return `...
## 输出要求
请以 JSON 格式输出大纲，结构如下：

{
  "node_title": "节点标题",
  "level": "层级名称",
  "sections": [
    {
      "column": "栏目名称（严格按体例规定）",
      "required": true/false,
      "writing_guide": "写作要点",
      "length_suggestion": "篇幅建议",
      "content_points": ["本栏目要写的具体内容要点"]
    }
  ],
  "key_points": ["重点"],
  "difficulties": ["难点"],
  "source_refs": [{ "file": "文件名", "relevance": "高|中|低" }]
}

要求：
1. sections 中的栏目必须严格按体例规定的顺序和名称
2. content_points 必须基于参考素材，具体可执行
3. 只输出 JSON，不要输出其他内容
`;
}
```

---

## 2. 解析逻辑

大纲存储在 `outline_versions.content`，当前直接存 JSON，无需改解析逻辑，只需确保前端能读取新的 `sections` 字段。

---

## 3. 前端大纲展示改造

### 当前展示

大纲以 `objectives / key_points / structure` 分块展示。

### 改造后

按 `sections` 数组顺序展示，每个栏目一个卡片：

```tsx
function OutlineDisplay({ outline }: { outline: any }) {
  // 兼容新旧两种格式
  if (outline.sections) {
    return (
      <Space direction="vertical" style={{ width: '100%' }}>
        {outline.sections.map((sec: any) => (
          <Card key={sec.column} size="small"
            title={<span>{sec.column} {sec.required ? '' : <Tag>可选</Tag>}</span>}
          >
            <p style={{ color: '#888', fontSize: 12 }}>{sec.writing_guide}</p>
            <ul>
              {sec.content_points.map((p: string, i: number) => (
                <li key={i}>{p}</li>
              ))}
            </ul>
            <div style={{ color: '#aaa', fontSize: 11 }}>篇幅建议：{sec.length_suggestion}</div>
          </Card>
        ))}
      </Space>
    );
  }
  // 旧格式兼容
  return <LegacyOutlineDisplay outline={outline} />;
}
```

---

## 改造顺序

1. 改 `outline.prompt.ts`
2. 改前端大纲展示组件（兼容新旧格式）
3. 测试：重新生成大纲，验证栏目结构正确
