## 实施方案

**推荐：顺序实施，不使用 AgentTeam**

**理由：**
- 改动涉及核心功能，需要谨慎测试
- LLM 抽象层风险较高，需要充分验证
- 体例优化依赖 LLM 抽象层，必须等待
- 质量和稳定性优先于速度

详见：[04-实施计划与任务编排.md](./04-实施计划与任务编排.md)

---

## 实施顺序

### 第一阶段：体例功能完善（3-4小时）
1. 添加体例编辑组件
2. 修改容器组件支持编辑模式
3. 前端生成前检查体例
4. 后端注入体例到 prompt

### 第二阶段：LLM 抽象层（2-3小时）
1. 创建 LLM 接口和工厂
2. 实现 Anthropic 和 DeepSeek Provider
3. 修改 AgentService 使用工厂
4. 测试切换功能

### 第三阶段：任务编排（可选，1-2小时）
1. 为不同任务配置不同模型
2. 成本优化验证
