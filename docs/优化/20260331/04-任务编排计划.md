# 任务编排计划（AgentTeam）

## 模块：多模型协作与任务分配

### 目标
利用不同模型的优势，实现成本优化和质量提升

---

## 一、任务分类

### 1.1 按成本和质量分类

| 任务类型 | 推荐模型 | 原因 |
|---------|---------|------|
| 体例分析 | DeepSeek | 结构化分析，成本低 |
| 目录生成 | Claude | 需要创造性，质量高 |
| 大纲生成 | Claude | 需要逻辑性，质量高 |
| 正文生成 | Claude | 需要文采，质量高 |
| 改写/扩写/精简 | DeepSeek | 规则性操作，成本低 |

---

## 二、实现方案

### 2.1 任务级别的模型选择

**方案 A：环境变量控制（简单）**

为不同任务设置不同的环境变量：

```env
# 体例分析用 DeepSeek
STYLE_ANALYSIS_PROVIDER=deepseek

# 内容生成用 Claude
CONTENT_GENERATION_PROVIDER=anthropic
```

**方案 B：动态选择（灵活）**

在 LLMFactory 中添加任务类型参数：

```typescript
createProvider(taskType?: string): LLMProvider {
  let provider = this.configService.get('LLM_PROVIDER', 'anthropic');

  // 根据任务类型覆盖
  if (taskType === 'style-analysis') {
    provider = this.configService.get('STYLE_ANALYSIS_PROVIDER', provider);
  } else if (taskType === 'content-generation') {
    provider = this.configService.get('CONTENT_GENERATION_PROVIDER', provider);
  }

  // 创建对应的 provider
  // ...
}
```

## 五、配置示例

### 5.1 推荐配置
**文件：`backend/.env`**

```env
# 默认使用 Claude
LLM_PROVIDER=anthropic

# 体例分析使用 DeepSeek（成本优化）
STYLE_ANALYSIS_PROVIDER=deepseek

# 内容生成使用 Claude（质量优先）
CONTENT_GENERATION_PROVIDER=anthropic

# Anthropic 配置
ANTHROPIC_API_KEY=sk-xxx
ANTHROPIC_BASE_URL=https://api.anthropic.com
ANTHROPIC_MODEL=claude-sonnet-4-6

# DeepSeek 配置
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

## 六、未来扩展

### 6.1 更细粒度的控制

可以为每个具体操作设置模型：

```env
DIRECTORY_GENERATION_PROVIDER=anthropic
OUTLINE_GENERATION_PROVIDER=anthropic
CONTENT_GENERATION_PROVIDER=anthropic
REWRITE_PROVIDER=deepseek
EXPAND_PROVIDER=deepseek
COMPRESS_PROVIDER=deepseek
```

### 6.2 智能路由

根据内容长度、复杂度自动选择模型：

```typescript
selectProvider(taskType: string, contentLength: number): string {
  if (taskType === 'rewrite' && contentLength < 500) {
    return 'deepseek';  // 短文本用便宜的
  }
  return 'anthropic';  // 长文本用质量高的
}
```
