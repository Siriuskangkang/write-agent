# 目录生成改造方案

## 问题

当前 prompt 要求输出固定的两层结构（章/节），与体例定义的三层结构（模块/项目/任务）不匹配。

---

## 改造范围

1. `directory.prompt.ts` — 输出结构改为通用节点树
2. `content.service.ts: parseDirectory()` — 解析新结构
3. `DirectoryTree` 前端组件 — 渲染层级标签

---

## 1. directory.prompt.ts 改造

### 当前输出格式

```json
{
  "chapters": [
    {
      "key": "ch1",
      "title": "第一章 章节标题",
      "sections": [
        { "key": "ch1-s1", "title": "1.1 小节标题", "material_support": "充足" }
      ]
    }
  ]
}
```

### 新输出格式（通用节点树）

```json
{
  "nodes": [
    {
      "key": "m1",
      "level": "模块",
      "title": "第1模块 人工智能基础认知",
      "description": "模块概述",
      "children": [
        {
          "key": "m1-p1",
          "level": "项目",
          "title": "项目1 探索人工智能在生活中的应用",
          "description": "项目描述",
          "children": [
            {
              "key": "m1-p1-t1",
              "level": "任务",
              "title": "任务1 认识身边的人工智能",
              "description": "任务描述",
              "material_support": "充足"
            }
          ]
        }
      ]
    }
  ]
}
```

### 改造后的 prompt 关键部分

```typescript
export function buildDirectoryPrompt(params: {...}): string {
  // 有体例时，从体例中提取层级信息
  const levelGuide = params.stylePrompt
    ? `请严格按照体例规定的层级结构生成目录。`
    : `请使用默认的章/节两层结构。`;

  return `...
## 输出要求
${levelGuide}

请以 JSON 格式输出，格式如下：
{
  "nodes": [
    {
      "key": "唯一标识",
      "level": "层级名称（如：模块、项目、任务）",
      "title": "标题（含编号，如：第1模块 xxx）",
      "description": "简要描述",
      "material_support": "充足|一般|不足（仅叶子节点填写）",
      "children": [ ...子节点，结构相同... ]
    }
  ]
}

要求：
1. 顶层节点数量等于 ${params.targetChapters}
2. 编号格式严格按体例规定
3. 叶子节点（最底层）必须填写 material_support
4. 只输出 JSON，不要输出其他内容
`;
}
```

## 2. 解析逻辑改造

### 当前解析（`content.service.ts`）

```typescript
// 将 chapters/sections 两层结构转为数据库节点
chapters.forEach((ch, ci) => {
  nodes.push({ node_type: 'chapter', title: ch.title, ... });
  ch.sections.forEach((sec, si) => {
    nodes.push({ node_type: 'section', title: sec.title, ... });
  });
});
```

### 改造后

```typescript
// 递归解析通用节点树
function flattenNodes(nodes: any[], parentId: string | null, depth: number): DbNode[] {
  const result: DbNode[] = [];
  nodes.forEach((node, i) => {
    const id = generateId();
    result.push({
      id,
      parent_node_id: parentId,
      node_type: node.children?.length ? 'chapter' : 'section',
      level_label: node.level,   // 新增字段：存储"模块"/"项目"/"任务"
      title: node.title,
      description: node.description,
      material_support: node.material_support,
      order_index: i,
      depth,
    });
    if (node.children?.length) {
      result.push(...flattenNodes(node.children, id, depth + 1));
    }
  });
  return result;
}
```

### 数据库字段变更

`directory_versions.content` 节点新增 `level_label` 字段，存储体例层级名称（模块/项目/任务），用于前端显示。

## 3. 前端目录树改造

### 改造点

在节点标题前显示层级标签：

```tsx
// DirectoryTree 节点渲染
function renderNodeTitle(node: DirectoryNode) {
  return (
    <span>
      {node.level_label && (
        <Tag size="small" color="blue">{node.level_label}</Tag>
      )}
      {node.title}
    </span>
  );
}
```

### 兼容性

`level_label` 为可选字段，旧项目没有该字段时正常显示标题，不影响已有数据。

---

## 改造顺序

1. 改 `directory.prompt.ts`（输出新格式）
2. 改后端解析逻辑（支持递归节点树）
3. 改前端目录树（显示层级标签）
4. 测试：重新生成目录，验证层级结构正确
