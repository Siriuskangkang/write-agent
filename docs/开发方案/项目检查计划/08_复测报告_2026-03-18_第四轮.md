## 2. 本轮已完成修复

### 2.1 search_terms / tokenizer 不一致（关键 bug）

**问题根因**：
- 切块时 `search_terms` 用 `extractTopSearchTerms` 生成，对短序列（≤4字）直接返回原句
- 检索时 query 用 `tokenizeForSearch` 产生 bigram
- 两者完全不匹配，导致关键词检索返回 0 结果

**修复**：
- `chunk.service.ts`：`search_terms` 改为用 `tokenizeForSearch(c.content)` 生成，与检索 query tokenizer 保持一致
- `keywords` 字段保留 `extractTopSearchTerms`（用于展示）

### 2.2 extractTopSearchTerms 单测 bug 修复

- 修复 `extractTopSearchTerms` 在去重集合上统计频率导致高频词排序错误的问题
- 改为在原始文本上直接统计词频
