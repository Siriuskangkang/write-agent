## 2. 本轮已完成修复

### 2.1 M10 正文生成停止恢复策略

**后端**
- `content.service.ts` 新增 `stopGeneration()` 方法：将 `STREAMING` 状态的结果标记为 `STOPPED`，幂等处理非 STREAMING 状态
- `content.controller.ts` 新增 `POST /:resultId/stop` 接口，带项目归属校验

**前端 useSSE**
- 新增 `heartbeat` 事件处理：每次收到任意数据重置 60s 超时计时器，超时后自动中断
- 新增网络断开自动重连：最多重试 3 次，间隔递增（2s/4s/6s），用户主动停止或流正常结束不触发重连
- `stop()` 设置 `stoppedByUserRef` 标志，防止用户停止后触发重连
- `start()` 切换到新请求前先 abort 旧连接，组件卸载时自动清理
- 移除所有 `console.log` 调试输出，保留必要的 `console.warn/error`
- SSE URL 统一使用同源 `/api` 路径（已在第二轮修复，本轮确认）

**前端 ChatPanel**
- 停止生成后主动回读最近一次 `result` 和 `citations`（通过 `restoreWorkspaceFromMessages`）
- 重复点击防抖：生成中禁用发送按钮

### 2.2 M14 前端工作台异常交互修复

**editorStore**
- 新增 `resetAll()` 方法，一次性清理所有编辑器状态

**projects/[id]/page.tsx**
- 切换项目时先调用 `resetAll()` 清理上一个项目的状态
- 离开项目（useEffect cleanup）时也调用 `resetAll()`
- 从 `project_state` 恢复 `currentDirectoryVersionId`、`selectedChapterNodeId`、`selectedSectionNodeId`
- 新增防抖 400ms 的 `project_state` 写路径：监听 `currentDirectoryVersionId`、`selectedChapterNodeId`、`selectedSectionNodeId` 变化后自动同步到后端
- 工作台顶部新增"设置"按钮，跳转到 `/projects/[id]/settings`

**DirectorySidebar**
- 优先从 `project_state.current_directory_version_id` 加载指定版本目录
- 目录版本变更时清理 `selectedChapterNodeId`、`selectedSectionNodeId`、`currentOutline`、`currentResult`、`citations`

### 2.3 search-tokenizer 单测修复

- `extractTopSearchTerms` 改为在原始文本上直接统计词频（不经过去重的 `tokenizeForSearch`），保留重复词的频率信息，确保高频词能正确排到 top N
