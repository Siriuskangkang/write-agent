# 真实场景与边界矩阵

这个文件定义后续检查必须覆盖的真实使用场景、异常场景和边界场景。

如果某个模块修复后没有覆盖这些场景中的相关项，就不能算“检查完成”。

## 一、真实使用场景

| 场景ID | 场景名称 | 场景说明 | 覆盖模块 |
|---|---|---|---|
| `S01` | 新用户首次使用 | 注册、登录、创建第一个项目、上传第一批素材、生成目录 | `M01` `M02` `M03` `M04` `M08` |
| `S02` | 教材从零编写 | 新建空项目，先无素材，逐步补充素材并编写 | `M03` `M04` `M08` `M09` `M10` |
| `S03` | 批量素材处理 | 一次上传多份 PDF/DOCX/PPTX/MD/TXT，等待解析和重试失败项 | `M04` `M05` `M06` `M07` |
| `S04` | 分阶段写作 | 第一天只生成目录和部分大纲，第二天回来继续写正文 | `M08` `M09` `M10` `M12` `M14` |
| `S05` | 迭代修改正文 | 对同一结果多次改写、扩写、精简并查看版本变化 | `M10` `M12` `M14` |
| `S06` | 引用不足补料 | 发现素材不足后回到素材页补传文件，再重新生成正文 | `M04` `M06` `M07` `M10` `M11` |
| `S07` | 导出交付 | 生成目录、正文、引用后导出 Markdown 和 Word 并下载 | `M08` `M10` `M11` `M13` `M14` |
| `S08` | 长时间使用后回访 | 退出页面、刷新页面、隔天重新进入项目继续操作 | `M02` `M03` `M12` `M14` |

## 二、边界场景

| 场景ID | 场景名称 | 说明 | 覆盖模块 |
|---|---|---|---|
| `B01` | 空项目 | 项目存在但没有任何素材 | `M03` `M08` `M09` `M10` |
| `B02` | 空文件或极小文件 | 上传后内容为空或仅少量文本 | `M04` `M05` `M06` |
| `B03` | 超长内容 | 超长 PDF、超长 DOCX、超长正文生成 | `M05` `M06` `M10` |
| `B04` | 高碎片文本 | TXT 或 DOCX 中大量短段落、短标题 | `M05` `M06` |
| `B05` | 重复操作 | 连续快速点击上传、生成、导出、删除 | `M04` `M10` `M13` `M14` |
| `B06` | 多会话切换 | 同一项目多个会话来回切换 | `M12` `M14` |
| `B07` | 刷新恢复 | 刷新页面后目录、结果、引用、会话能否恢复 | `M02` `M12` `M14` |
| `B08` | 部分完成状态 | 有目录无大纲、有大纲无正文、有正文无导出 | `M08` `M09` `M10` `M13` |

## 三、异常场景

| 场景ID | 场景名称 | 说明 | 覆盖模块 |
|---|---|---|---|
| `E01` | 未登录访问 | 未登录直接访问项目页、素材页、工作台、导出接口 | `M02` `M14` `M15` |
| `E02` | 登录过期 | access token 过期、refresh 成功或失败 | `M02` `M14` |
| `E03` | 非法资源ID | 非法 UUID、已删除项目、已删除文件、已删除结果 | `M03` `M04` `M10` `M11` `M13` |
| `E04` | 解析失败 | 文件格式不支持、文件损坏、解析器报错 | `M04` `M05` |

| `E06` | 导出失败 | worker 失败、文件不存在、未完成就下载 | `M13` |
| `E07` | 重解析冲突 | 重解析中查询旧结果、删除文件后重解析 | `M04` `M05` `M06` |

|---|---|---|---|

## 五、验证证据要求

每个场景至少保留一种证据：

- 构建命令结果
- 接口请求与响应
- 页面截图或行为记录
- SSE 事件序列
- 数据库状态变化说明
- 错误信息或日志

## 六、判定规则

- 只覆盖主流程，不覆盖边界和异常，判定为“不完整”
- 只覆盖页面点击，不覆盖接口和数据落盘，判定为“不完整”
- 只看代码不实际执行，判定为“未验证”
- 边界场景出现失败但没有记录归属模块，判定为“不可验收”
