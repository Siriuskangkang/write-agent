## 2. 本轮已完成修复

### 2.1 工程与测试基线

- 前端 `package.json` 已补齐 `build`、`typecheck`、`test`
- 后端 Jest / e2e 对 `.js` 扩展导入的映射已补齐
- 后端 e2e 示例测试已改为不依赖完整数据库环境的 Nest 集成基线

### 2.2 后端主链路收口

- 文件、切块、检索、引用接口已补项目归属校验
- 文件删除/重解析已补 `citation_maps` 清理
- `ParseWorker` 只在切块成功后标记 `DONE`
- `Chunk.embedding` 实体已对齐数据库 `vector(1536)`
- Embedding 服务已接入：有 `OPENAI_API_KEY` 时生成向量，无配置时显式降级为 `null`
- 检索关键词分支的参数错误已修正
- `chunker` 已增加 overlap 和长段落拆分，降低上下文断裂与超长段聚合问题
- `TXT` 解析已改为优先识别标题样式段落并聚合正文，降低过碎 section
- 切块关键词提取与检索 query 已统一使用共享 tokenizer，增强中文教材场景下的可检索 token
- 会话消息写入接口已补齐：`POST /projects/:projectId/sessions/:sessionId/messages`
- 引用读取接口已收口到 `userId + projectId`
- 导出接口已补项目归属校验
- 导出 worker 已统一使用 `UPLOAD_DIR/exports`，修复写入路径与读取路径不一致
- 指定章节导出已真正按 `chapter_ids` 过滤目录和正文内容
- 导出 DTO 已要求 `scope=chapters` 时必须传 `chapter_ids`
- 认证模块已新增资料更新接口，可更新当前用户昵称
- 注册与改密的最小密码长度已统一为 8 位

### 2.3 前端工作台与项目设置

- `useSSE` 已切回同源 `/api` 路径
- 工作台 `ChatPanel` 已接通会话拉取、消息持久化、刷新恢复
- 大纲结果已独立保存为 `outline`，不再混入正文结果状态
- 正文完成后会主动回读 `result` 与 `citations`
- 停止生成后会尝试回读最近一次 `result` 与 `citations` 做最小恢复
- SSE 前端已兼容 `heartbeat` 事件
- 快捷操作增加前置校验，避免未满足条件时写入假消息
- 新增项目设置页：`/projects/[id]/settings`
- 工作台已新增设置入口
- 项目卡片“编辑”已跳转到项目设置页
- 工作台当前目录版本、进行中章节、进行中小节会同步回 `project_state`
- 重新进入项目时会优先从 `project_state` 恢复目录版本与选中节点
- 新增个人设置页：`/settings`
- 个人设置页已支持读取当前账号、修改昵称、修改密码
- 项目列表已补个人设置入口
- 导出弹窗已补轮询清理、失败原因展示
- 前端 `npm test` 已改为先生成 Next 类型再执行 `tsc --noEmit`，最小测试基线更稳定
